# Manifest

Main contents:

- `code_overlay/`: TGR-Net and OW-OVD overlay code; legacy Mamba-KAT implementation identifiers are retained.
- `configs/`: training, evaluation, and ablation configs.
- `env/`: `ow_ovd` conda and pip environment records.
- `data_assets/`: lightweight text/attribute assets.
- `checkpoints/`: target directory for trained model checkpoints.
- `results/`: paper table CSVs and semantic matching summaries.
- `tests/`: smoke tests for adapter, CWD loss, and configs.
- `CITATION.cff`: citation metadata for this release.
- `RELEASE_NOTES.md`: release scope and naming information.

The complete file list is in `MANIFEST.files.txt`.
