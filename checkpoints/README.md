# Checkpoints

Place the trained Mamba-KAT checkpoint here, for example:

```text
mambakat_task1_full.pth
```

This local workspace did not contain the trained adapter checkpoint at packaging time. The base YOLO-World pretrained checkpoint is also not included; place it in the base repository under:

```text
pretrained_models/yolo_world_v2_l_obj365v1_goldg_pretrain-a82b1fe3.pth
```
