# TGR-Net v1.0.0

This is the archival source-code and reproduction release corresponding to the TGR-Net manuscript.

The implementation was developed under the internal name `Mamba-KAT`. Legacy identifiers are intentionally retained in source files, configurations, tests, and result labels to preserve exact correspondence with the evaluated implementation. The release title and documentation use the manuscript name TGR-Net.

The archive includes source code, training and evaluation configurations, weather-synthesis utilities, environment records, smoke tests, and machine-readable result summaries. It does not include private DriverWeather images, third-party datasets, or trained model checkpoints.
